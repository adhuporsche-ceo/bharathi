1. SYSTEM OVERVIEW
--------------------------------------------------------------------------------
Bharthi DSA Visualizer is a real-time, interactive educational web platform
specifically engineered for undergraduate Computer Science students at Kumaraguru
College of Technology (KCT). It transforms abstract algorithmic concepts into
live, interactive sensory experiences through synchronized visual state transitions,
algorithmic audio synthesis, real-time peer collaboration simulation, multi-algorithm
racing benchmarks, and automated exam dry-run worksheets.

Primary Capabilities:
- Real-time Animation Canvas: Visual representations for Sorting, Searching,
  Stack (LIFO canister), Queue (FIFO pipeline), Graph (BFS levels), Dynamic
  Programming (0/1 Knapsack matrix), and Backtracking (N-Queens chessboard).
- Web Audio API Sound Synthesizer: Dynamic pitch mapping for array comparisons,
  swaps, tree visits, and algorithmic completion chimes.
- Real-Time Collaborative Classroom: Peer activity streams, real-time online student
  counter, live DAA viva doubt-solving board, and weekly challenge leaderboards.
- Multi-Algorithm Race Arena: Synchronous side-by-side execution of 2 algorithms
  on identical datasets with live operation counters and podium announcements.
- Exam Dry Run Worksheet Generator: Tabular trace of passes, pointers, and memory
  with 1-click CSV export and Markdown formatting for university lab record books.
- Interactive Master Theorem Solver: Solves T(n) = aT(n/b) + Theta(n^k) with
  parameter sliders, logarithmic threshold math, and visual recursion tree layers.

5. REAL-TIME SUB-SYSTEMS IN DETAIL
--------------------------------------------------------------------------------
A. Web Audio API Synthesizer (src/utils/soundEffects.ts):
   - Generates tones directly in browser memory without external MP3/WAV assets.
   - Frequency Mapping: Maps array values (10 to 100) onto pitch scale 220Hz - 1046Hz
     using triangle oscillator waves for smooth pleasant tone.
   - Swap Swoop: Sawtooth wave glide ramping from 600Hz down to 260Hz.
   - Comparison Ping: Crisp 440Hz sine burst (0.05s duration).
   - Success Fanfare: Ascending arpeggio across C5 (523Hz), E5 (659Hz), G5 (784Hz),
     and C6 (1046Hz).
   - Global volume regulation with full Mute/Unmute support across UI buttons.

B. Live Classroom Session (src/components/LiveClassroomSession.tsx):
   - Simulated real-time WebSocket/peer heartbeat stream with pulse indicators.
   - Online student activity counter fluctuating between 28 and 52 active students.
   - Real-time peer activity stream: records peers completing dry runs and quizzes.
   - Interactive Doubts Stream: Students can submit viva questions by topic.
     Automated faculty AI mentor answers with academic correctness within 2.5s.
   - KCT Lab Challenge Tasks with 10-20 marks point allocations.

C. Multi-Algorithm Race Arena (src/components/AlgorithmComparator.tsx):
   - Independent step tracking for Racer 1 (Track A) and Racer 2 (Track B).
   - Real-time tick timer running at 120ms intervals.
   - Dynamic progress calculations (% complete = step / totalSteps).
   - Visual race track showing live array mutations side-by-side.
   - Auto-detection of winner with comparison efficiency calculation.

D. Real-time Variable Watcher & Invariant HUD (src/components/RealtimeVariableWatcher.tsx):
   - Live displays of comparison counters and memory swaps.
   - Dynamically mapped register pills displaying CPU state (e.g. i=3, j=4, min=1).
   - Formal loop invariant statement for university lab examinations.

E. Interactive Playback Deck (src/components/PlaybackDeck.tsx):
   - Slider scrubber: Drag smoothly across 0% to 100% of execution timeline.
   - Speed multipliers: 0.5x, 1x, 2x, 4x.
   - Automated transport loop with edge-case protection (stops at steps.length - 1).
   - Presets: Random 8, Nearly Sorted (Best Case), Inverted (Worst Case), and
     custom array modal input parser.

F. Master Theorem Solver (src/components/MasterTheoremSolver.tsx):
   - Real-time computation of critical exponent log_b(a).
   - Comparison with polynomial exponent k against precision epsilon 0.001:
     * Case 1: k < log_b(a) -> Theta(n^(log_b a))
     * Case 2: k = log_b(a) -> Theta(n^k log n)
     * Case 3: k > log_b(a) -> Theta(n^k)
   - Visual recursion tree depth layers: Level 0 (cn^k), Level 1 (a*c(n/b)^k),
     Level 2 (a^2*c(n/b^2)^k), and Leaf Count (n^(log_b a)).

G. Dry Run Worksheet (src/components/DryRunWorksheet.tsx):
   - Tabular trace corresponding to Anna University / KCT DAA record standards.
   - 1-Click CSV file generator via data URI encoding.
   - 1-Click Markdown table clipboard copy.
   - Row click listener: Jumps canvas visualizer directly to the clicked step index.
